# 🫂 Contributing to Yi-Jing Agent

We welcome contributions from everyone! Here's how you can help:

## Ways to Contribute

### 1. 🌐 Translations
Translate the design document or this README into:
- English (已完成)
- Japanese
- Korean
- Vietnamese
- Any language!

### 2. 🧩 Hexagram Strategy Table
The 64 hexagram → strategy mapping is the heart of the fault-tolerance system. If you've discovered a new failure mode and its corresponding strategy:
1. Open an issue with your proposed mapping
2. Or submit a PR adding to `src/hexagram_table.py`

### 3. 🐛 Bug Reports & Feature Requests
Open an issue with:
- Clear description of the bug/feature
- Steps to reproduce (for bugs)
- Expected behavior

### 4. 💡 New Examples
Share your own 六爻 lifecycle walkthroughs! Add them to `examples/`.

### 5. 🛠️ Tools & Integrations
- Visualization dashboard for hexagram history
- VS Code extension
- Integration with LangChain, AutoGPT, CrewAI

## PR Guidelines

1. Fork the repo
2. Create a feature branch: `git checkout -b feature/my-awesome-addition`
3. Commit with clear messages
4. Push and open a PR
5. Wait for review

## Code Style

- Python: Follow PEP 8
- Chinese docs: Traditional Chinese (Cantonese preferred)
- English docs: Clear, concise, not necessarily native-level

## Code of Conduct

Be respectful. This is a cross-cultural project — the I Ching belongs to everyone.

---

**Thank you for contributing!** 🌟
